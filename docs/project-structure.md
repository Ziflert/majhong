# Структура файлов проекта

Этот документ задаёт правила размещения файлов. Если новый файл не подходит ни под один раздел,
сначала уточнить архитектурное решение и обновить карту проекта.

## Корень проекта

В корне остаются только файлы конфигурации/документации проекта и стандартные каталоги Unity:
`Assets/`, `Packages/`, `ProjectSettings/`, `Tools/`, `docs/`, `Tiles/`, `Screenshots/`.
Одноразовые скрипты, выгрузки, снимки, логи и тестовые дампы в корень не помещаются.

## Исходный код

- `Assets/Scripts/Mahjong/Rules/` — чистые правила игры без Unity API.
- `Assets/Scripts/Mahjong/Controls/` — чистые модели настроек и поведения UI.
- `Assets/Scripts/Mahjong/Localization/`, `Knowledge/`, `Replay/`, `Net/`, `Bots/` — чистые
  прикладные подсистемы по назначению.
- `Assets/Scripts/MahjongView/` — Unity-представление, сцена, камеры и визуальные компоненты.
- `Assets/Editor/` — editor-only capture и инструменты запуска.
- `Assets/Tests/Editor/`, `Assets/Tests/PlayMode/` — тесты соответствующего уровня.
- `Tools/` — headless-инструменты, сверки и генераторы, не являющиеся runtime-кодом игры.

Новый чистый код нельзя класть в `MahjongView`; новый MonoBehaviour нельзя класть в `Rules` или
`Controls`. Каждая новая `.cs` в `Assets/` должна иметь Unity `.meta`.

## Документация

- `docs/project-map.md` — короткий индекс каталогов, точек входа и команд.
- `docs/project-structure.md` — эти правила размещения.
- `docs/plan.md` — только текущий план и статус задач.
- `docs/journal.md` — только значимые вехи и решения.
- `docs/session-context.md` и тематические handoff-файлы — короткий контекст для следующей AI-сессии,
  на английском языке.
- `docs/asset-sources.md` — происхождение внешних референсов и лицензии.

## Артефакты запусков

- `Logs/` — Unity-логи и XML результатов тестов. Снимки сюда запрещены.
- `Screenshots/current/` — последний канонический визуальный прогон.
- `Screenshots/archive/` — старые кадры, ручные сравнения и crops; структура и команды в
  `Screenshots/README.md`.
- `Library/`, `Temp/`, `UserSettings/`, `.local/` — машинные или локальные данные, не редактировать
  вручную и не коммитить.

## Ассеты и референсы

- `Assets/Resources/` — только ассеты, которые нужны игре во время запуска.
- `Tiles/` — исходники лиц костей и генераторы атласа.
- `examples/` — внешние визуальные референсы. Для каждого используемого референса нужна запись в
  `docs/asset-sources.md`; не выдавать референс за игровой ассет.
- `UI/` — отдельный экспериментальный UGUI-черновик. Он не является активным runtime-слоем, пока
  это явно не изменено в архитектурном решении и карте проекта.

## Git и уборка

Сгенерированные файлы должны быть перечислены в `.gitignore`. Перед коммитом проверять `git status`
и не добавлять `Library/`, `Logs/`, текущие/архивные PNG, временные JSON и локальные настройки.
Значимый рефакторинг структуры оформлять отдельным коммитом с префиксом `chore:`.
