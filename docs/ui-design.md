# Дизайн интерфейса — Mahjong Sport & Classic

Дата: 2025-11-05
Статус: Архитектурный замысел UI-слоя (UGUI) поверх существующей модели `Controls/`. Документ расширен
спецификацией визуального 3D-слоя, пользовательской камеры и двумя вариантами интерфейса.

## 0.1. Варианты внешнего вида

В игре должны остаться два выбираемых профиля интерфейса:

1. **Минималистичный** — текущий внешний вид как совместимый режим: плоские спокойные панели,
   существующая компоновка, минимум декоративных элементов, без обязательных новых ассетов.
   Это режим по умолчанию для слабых машин и для игроков, которым важна максимальная читаемость.
2. **Studio / Quiet Luxury** — новый основной визуальный профиль: глубокий нефритовый стол,
   тёплая слоновая кость костей, тонкие золотые маркеры, мягкие тени и небольшие акцентные
   орнаменты. Сохраняем плотность информации текущего интерфейса, но улучшаем иерархию,
   расстояния, типографику, состояния hover/active/disabled и анимации. Декор не должен перекрывать
   кости или менять порядок действий.

Переключатель профиля хранится рядом с цветовой схемой и переживает перезапуск. Цветовые пресеты
(`night`, `dawn`, `bamboo`, `ivory`) остаются независимыми от профиля: старый профиль можно
использовать с любой палитрой. Все действия продолжают идти через `Controls/`, новый профиль
не дублирует игровую модель.

## 0.2. Спецификация 3D-визуала и ассетов

### Кости

- Перерисовать полный набор лиц на основе референсов из `examples/`: единая сетка, одинаковая
  толщина штриха, чистая иероглифическая/иллюстративная графика, без случайного смешения стилей.
- Сделать SVG-исходники для 34 лиц, цветы, рубашку и выбранное состояние; собирать их в атлас
  существующим `Tools/Tiles/build_atlas.py`.
- Две арт-дирекции для выбора: `Classic Ink` (чёрная тушь + красный/зелёный/синий акцент) и
  `Botanical Quiet` (приглушённые природные цвета). Не использовать чужие изображения без
  проверенной лицензии; для внешних ассетов вести `docs/asset-sources.md` с URL, автором,
  лицензией, датой доступа и переработанными файлами.
- Рубашка, рамка, скругление и тень должны читаться в 3D под разными углами; лицо не должно
  зависеть от цвета стола. Выбранная кость обозначается формой/подъёмом и тонким контуром,
  а не только цветом.

### Стол и окружение

- Заменить примитивный стол на модульные low-poly ассеты: рама, сукно, центральная зона,
  четыре места игроков, маркер разрыва стены, кости и кубики. Декоративные детали — крупные,
  редкие, матовые; никаких мелких частиц, постоянно мигающих подсветок и текстурного шума.
- Использовать мягкий key/fill/rim-свет, ambient occlusion только там, где он помогает отличать
  стопки и комбинации. Цель — визуальная глубина без потери контраста лиц костей.
- Открытые комбинации должны иметь отдельные визуальные острова: зазор между группами, воздух
  вокруг боковой заявленной кости и небольшая метка «только что объявлено». Кнопка заявки не
  имеет права закрывать руку, сбросы или другие кнопки.

## 0.3. Камера и полезные действия пользователя

Игра остаётся полноценной 3D-сценой. Камера ограничена орбитой вокруг центра стола, чтобы игрок
не мог потерять стол или заглянуть под геометрию:

- **средняя кнопка мыши + перетаскивание** — вращение вокруг стола по горизонтали и вертикали;
- **колесо мыши** — плавное приближение/отдаление с ограничителями;
- **Home** — вернуть удобный вид по умолчанию;
- HUD и панели остаются прикреплены к экрану и переразмещаются при изменении масштаба/камеры;
- камера не реагирует на вращение/zoom поверх меню, книги правил, результата и приветственного
  экрана; левая кнопка остаётся выбором костей и UI;
- в дальнейшем добавить в меню: инверсия вертикали, чувствительность вращения, пресеты
  «обзор стола / мой игрок / крупный план», опциональное приближение двойным кликом по месту.

Обязательные PlayMode-проверки: границы дистанции и pitch, возврат Home, отсутствие движения
камеры в модальных экранах, сохранение попадания по кнопкам после поворота и отсутствие ухода
HUD за пределы кадра.

## 0. Принцип разработки (важно)

Проект уже имеет зрелую **модель UI** (`Controls/TitleScreen`, `Controls/GameMenu`, `Controls/ActionPrompt` и т.д.) —
чистые C#-классы без `UnityEngine`, полностью покрытые headless-тестами. **Новый визуальный слой НЕ должен
пересоздавать эту модель.** Его задача — перерисовать строки/команды модели в современный UGUI-формат.

Архитектура визуального слоя:

```
Controls/ (модель — менять только через неё)
        ↓
UI/Controls/      — контроллеры: MainMenuController, GameMenuController, ActionPromptController
UI/Models/        — ViewModels: TitleViewModel, MenuViewModel, HudViewModel (адаптеры к Controls/)
UI/Themes/        — ScriptableObject: ColorTheme, FontTheme, LayoutTheme, SoundTheme
UI/Prefabs/       — префабы кнопок, плашек, карточек, иконок
UI/Sprites/       — иконки, текстуры фонов, текстуры кнопок
UI/Materials/     — материалы (стекло, свечение, тени)
```

Правило: ни одна правка UI не должна ломать `Controls/*` или headless-проверки. Новые строки меню
добавляются только в модель + тест.

## 1. Визуальная концепция

**Стиль:** «Тихий азарт» — современный минимализм с азиатской эстетикой. Ничего кричащего:
глубокие природные тона, мягкие тени, тонкие золотые акценты. Интерфейс не перетягивает внимание
от костей — он становится невидимой подложкой.

### 1.2 Типографика

- Заголовки: **Noto Serif Display** (подключение через `Resources/Fonts`), размеры 24/20/16px
- Основной текст: **Noto Sans**, 13px, межстрочный интервал 1.35
- Числа/очки: **Noto Sans Mono**, 14–18px, ширина фиксирована для верт
- Кнопки: **Noto Sans Medium**, 14px, LETTERSPACING +2

### 1.3 Формы и эффекты

- Скругление углов: 10px (кнопки), 14px (панели), 6px (иконки)
- Тень панели: `0/2/16`, `rgba(0,0,0,0.35)`, смещение `-4/0/0` (внутренняя, подложка)
- Подъём при hover: `0/8/24`, `rgba(46,139,112,0.15)`, цвет основного акцента
- Градиенты: минимальны — только на логотипе и фоновых элементах (радиальный, прозрачность 0–12%)
- Золотой бордюр: 1px `C9A250` с прозрачностью 40% на активных панелях настроек

## 2. Слои интерфейса (z-order)

| Слой | Canvas | Назначение |
|---|---|---|
| `GameLayer` | Canvas `GameUI` | 3D-сцена, плитки, эффекты на столе |
| `OverlayLayer` | Canvas `GameUI` (WorldProjection) | курсор, подсказки, маркеры доступных ходов, всплывающие тултипы |
| `HUDLayer` | Canvas `GameUI` (ScreenProjection) | игровая строка, таймеры, действия, очки мест |
| `SystemLayer` | Canvas `GameUI` (ScreenProjection) | пауза, уведомления (сохранено/ошибка) |
| `MenuLayer` | Canvas `GameUI` (ScreenProjection) | главный экран, настройки, экраны (модалки поверх всего) |

Каждый слой — отдельный `Canvas` с собственным `SortingOrder` (500, 600, 700, 800, 900).

(каскадное появление). Фон: медленный зум текстуры сукна (коэфф. 1.02 за 30с).

|---|---|

| **Кастомная схема** | выбор основного/акцентного/фона/текста через цветовой пикер (HSV + HEX) |

без применения к игре (кнопка «Применить» внизу панели). Настройки сохраняются в
`PlayerSettings` и читаются при следующем запуске.


**Элементы HUD:**
- Верхняя строка: статус (ваш ход / ожидание / чей ход), таймер решения, информация о руке, счёт
- Центр: 3D-стол с подсветкой доступных для кона костей (золотое кольцо вокруг)
- Нижняя строка: ваши кости, панель действий (кнопки 1–5), быстрые действия
- Места соперников: табличка с ветром, очками, статусом (активен / думает / ожидает)
- Сбросы: блоки по 6 костей, сгруппированные по игрокам

**Эффекты:**
- Подсветка доступных действий: золотая обводка + пульсация
- Курсор над костями: увеличение на 5% + тень
- Анимация хода: кость скользит от игрока к центру + звук удара
- Оповещение о доступном коне: вибрация края экрана (мягкий свёт) + иконка ⚡
- Победа: конфетти из костей (частицы), золотой флер поверх стола

## 7. Технический стек UI-слоя

- **Unity UGUI** — все панели, Canvas с 5 слоями, `GraphicRaycaster` на каждом
- **ScriptableObject** — `ColorTheme`, `FontTheme`, `LayoutTheme`, `SoundTheme`, `GameConfig`
- **Animation** — `DOTween` или нативные `CanvasGroup.alpha` + `RectTransform.anchoredPosition` с кривыми
- **Shader Graph** (опц.) — стекло для панелей настроек, свечение для акцентов
- **TextMeshPro** — весь текст (лучшая поддержка кириллицы)

| `UI/ViewModels/TitleViewModel.cs` | Адаптер `TitleScreen` → UI-элементы |
| `UI/ViewModels/MenuViewModel.cs` | Адаптер `GameMenu` → UI-элементы |
| `UI/ViewModels/HudViewModel.cs` | Данные HUD из `MahjongGame` |

### 7.2 ScriptableObjects

| Тип | Поля |
|---|---|
| `ColorTheme` | Background, Surface, Primary, Accent, TextMain, TextMuted, Critical, Info, Border (9 × Color + AlphaModulate) |
| `FontTheme` | Заголовки (font + size + lineHeight), Основной, Числа, кастомизации (bold, letterSpacing) |
| `LayoutTheme` | Скругления, отступы, размеры кнопок, тени |
| `GameConfig` | Мапа клавиш (JSON), громкости, качество, масштаб, текущая тема (GUID) |

Сохранение: `PlayerPrefs` для мелких настроек + отдельный JSON в `Application.persistentDataPath`
(резерв при повреждении конфига). Формат версиируется: `"ui-config-v1"`.

## 10. Этапы реализации

### Этап 1 — Каркас (MVP)
1. Создать Canvas `GameUI` с 5 слоями (`SortingOrder`: GameLayer 500 … MenuLayer 900)
2. Реализовать `ColorTheme` + 3 пресета (тёмная/светлая/дерево)
3. `UIManager` — базовые переходы `MainMenu → Settings → GameHUD → Pause`
4. Префаб `BaseButton` + состояния
5. Главный экран (скелет + меню-строки)

### Этап 2 — Настройки + кастомизация
6. `SettingsManager` — вкладки, сохранение/загрузка
7. Пресеты тем + превью в реальном времени
8. Цветовой пикер (нативный `UnityEditor.ColorPicker` для редактора / кастомный HSV-круг для билда)
9. Звуки интерфейса (hover/click/switch)

### Этап 3 — Игровой интерфейс
10. HUD: строка статуса, таймеры, счетчики
11. Панель действий с анимациями
12. Индикаторы мест, статус ботов
13. Экран результата руки + итоговая таблица сессии

### Этап 4 — Полировка
14. Анимации переходов (выезд/исчезновение, blur-fade)
15. Частицы эффектов (победа, конг)
16. Звуковое оформление (HUD-подсказки, confirm, error)
17. Тесты PlayMode: UI-слой перерисовывает модель корректно (сравнение текста/цветов)

### Этап 5 — Релиз
18. Экран обучения (первый запуск)
19. Таблица рекордов (локальный лидерборд)
20. Достижения
21. Адаптация под разные соотношения сторон (16:9, 21:9, вертикальные)

## 11. Критерии качества

- [ ] Все 12 строк главного экрана и 10 строк меню читаются headless-тестами через ViewModel
- [ ] Тема применяется ко всем UI-элементам (нет «выскочивших» white-on-white)
- [ ] Кастомная схема сохраняет 6+ цветов без конфликта контраста (WCAG AA для текста)
- [ ] Масштаб интерфейса 0.75–1.5 без вылетов за кадр
- [ ] Производительность: 60 FPS при открытых панелях, без лишних `Graphics.DrawMesh`
- [ ] Анимации плавные (30–60 FPS, нет резких скачков)
- [ ] Все тексты двуязычны (RU/EN), переключение без пересборки
- [ ] Поддержка геймпада (оси + кнопки) + мыши
- [ ] Скриншоты из CLI (`InterfaceCapture`) покрывают все экраны
