## Правила импорта

- Предпочтение: собственные SVG/PNG/low-poly модели или CC0/известная коммерческая лицензия.
- Для каждого импортированного файла фиксировать URL страницы автора, имя автора, лицензию,
  дату доступа и изменения.
- Не копировать персонажей, логотипы, иероглифические композиции и наборы целиком из референса;
  использовать только общие идеи композиции и сделать собственные исходники.
- В итоговом билде не должно быть изображения с Pinterest/поиска без страницы первоисточника и лицензии.
