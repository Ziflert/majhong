# Unity-слой (3D-прототип)

Слой представления отделён от логики: `Assets/Scripts/Mahjong` не знает про Unity,
`Assets/Scripts/MahjongView` — это MonoBehaviour-обёртки.

| Файл | Назначение |
|---|---|
| `MahjongView/TileObject.cs` | 3D-тайл из примитивов: куб + текстовое поле на лицевой стороне |
| `MahjongView/TileLabel.cs` | Короткая подпись и цвета для каждого типа кости |
| `MahjongView/MahjongGame.cs` | Сборка сцены, сессия, ходы человека и ботов, ввод мышью |

## Как запустить

1. Создать новый проект Unity (3D, Built-in или URP).
2. Скопировать в него папки `Assets/Scripts/Mahjong` и `Assets/Scripts/MahjongView`.
3. Нажать Play. Пустая сцена подойдёт: `MahjongGame` создаёт камеру, свет, стол и сам
   добавляет себя в сцену через `RuntimeInitializeOnLoadMethod`.

Альтернатива: положить `MahjongGame` на пустой GameObject вручную и задать в инспекторе
`humanSeat`, `botDelay`, `randomSeed`.

## Что уже играется

- сессия из 16 рук (4 раунда × 4 руки), смена разыгрывающего;
- один человек (место 0) против трёх эвристических ботов;
- рука игрока выкладывается в ряд, клик по кости — снос;
- клавиша `H` — объявить Ху, если движок это разрешает;
- заявки: человек автоматически пасует, кроме Ху; боты решают сами;
- сбросы и открытые комбинации выводятся на столе, кости соперников — рубашкой вверх;
- сверху текст: номер руки, раунд, место, остаток стены, счёт;
- после руки — экран результата с расчётом выплат, затем следующая рука.

## Ограничения прототипа

- Нет анимаций, звука, ассетов: тайлы — разноцветные кубы с подписями (`1c`, `5d`, `E`, `Rd`).
- Человек не может объявлять Чи, Панг и Конг: ввод только снос и Ху. Движок это умеет,
  нужен UI выбора действия.
- Нет меню, настроек, паузы, сохранений.
- Ввод на `UnityEngine.Input` (legacy). Если проект настроен только на новый Input System,
  нужно включить Both в Player Settings или переписать ввод.
- Сцена генерируется кодом, `.unity`-файлов в репозитории нет намеренно.

## Проверка

Логика проверяется headless: `dotnet run --project Tools/RulesCheck` (24 группы, ~51 тыс. проверок).
Скрипты `MahjongView` компилируются только в Unity: вне редактора для них нужны заглушки,
поэтому `Tools/RulesCheck` собирает лишь `Assets/Scripts/Mahjong`.

Следующий шаг слоя представления — UI выбора действия (Чи/Панг/Конг/Пас), подсветка
доступных заявок и анимация хода.
