# Новый UI — план и ограничения

Дата: 2026-11-08
Статус: начат вертикальный срез нового экранного UI.

## Решение

Старый world-space UI не дорабатывается как основной интерфейс. Новый слой строится на одном
Screen Space Canvas с CanvasScaler и экранными якорями. Игровая модель, `Controls/`, локализация,
правила, сохранения и сетевой слой не меняются.

Первый срез включает игровой HUD: верхнюю строку, четыре фиксированные плашки мест, подсказку,
кнопку паузы и панель заявок. Старые `ReferenceHud`, `TableHud` и нижний world-space трей
отключаются только для обычного игрового экрана; их публичные API временно сохраняются для
совместимости тестов и инструментов.

## Правила нового слоя

- UI не использует координаты 3D-стола и не зависит от orbit/zoom камеры.
- Сетка задана в reference resolution 1280×720; `CanvasScaler` масштабирует её равномерно.
- Верхняя полоса, плашки игроков, подсказка и hand/action safe zones не пересекаются.
- Ширина панели задаётся сеткой, не длиной локализованной строки.
- Русский и английский текст уменьшается по размеру внутри фиксированной области, но не меняет
  положение соседних компонентов.
- Модальный UI должен перехватывать ввод и блокировать управление камерой.
- Техническая информация остаётся вне постоянного HUD и доступна через существующий F3-режим.

## Контрольные размеры

- Reference resolution: 1280×720.
- Верхняя полоса: 24 px от краёв, 44 px высотой.
- Верхние блоки: hand 250 px, rules 220 px, wall 170 px, clock 220 px.
- Player plates: 220×54 px; собственная плашка 250×60 px.
- Hint: 520×44 px, нижний safe zone начинается на 86 px.
- Action bar: по центру над hand safe zone, не более 5 кнопок.
- Цвета и шрифт берутся из существующих `UiStyle`/`UiFont`; новые RGB-литералы запрещены.

## Definition of Done вертикального среза

1. Canvas HUD виден в PlayMode без world-space плашек старого UI.
2. RU/EN, 1280×720 и 1920×1080 не дают обрезанного текста или выхода за экран.
3. Поворот и zoom камеры не меняют экранную композицию.
4. Кнопка паузы и кнопки заявок передают команды существующей модели игры.
5. `dotnet build Tools/RulesCheck/RulesCheck.csproj --no-restore` зелёный.
6. После визуальной проверки можно переносить меню, настройки и результат на тот же Canvas.
